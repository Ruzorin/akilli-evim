# space_projection — Donanım ve Görsel Psikoloji Rehberi

> **Modül 3: Space Projection (Tavan Projeksiyonu ve Derin Uzay İllüzyonu)**
> Yatakta uzanırken bakılan sıkıcı beyaz tavanı, hipnotik ve yavaş hareket eden bir nebulaya çevirmek. Düşük ışıklı, yavaş görseller insan psikolojisinde derin rahatlama ve güvenlik hissi yaratır.

## 🌌 Galaksi Projeksiyon Cihazı — Konumlandırma

### Cihaz Seçimi

| Özellik | Detay |
|---|---|
| **Tip** | Tuya/SmartLife uyumlu galaksi projeksiyon cihazı |
| **Özellikler** | Nebula (bulutsu) dönen disk + Yeşil lazer (yıldız) + RGB LED |
| **Bağlantı** | WiFi 2.4GHz (GL-MT3000 ağına bağlanır) |
| **HA Entegrasyonu** | LocalTuya (smart_diffuser modülündeki gibi) |
| **Öneri** | Tuya Galaxy Projector (500ml kapasiteli, nebula + lazer) |
| **Fiyat** | ~$25-40 |

### Konumlandırma

```
  ┌─────────────────────────────────────────────┐
  │                  ODA YAN GÖRÜNÜM               │
  │                                             │
  │         ┌─────────────────────┐             │
  │         │      TAVAN           │             │
  │         │  ░░░░░░░░░░░░░░░░░  │             │  ← Nebula tavana yansır
  │         │  ░░░░░░░░░░░░░░░░░  │             │
  │         └─────────────────────┘             │
  │                  ▲                          │
  │                  │ Işık                     │
  │                  │                          │
  │           ┌──────┴──────┐                  │
  │           │ Projeksiyon  │                  │  ← Yatak başucunda
  │           │ Cihazı       │                  │     doğrudan yukarı bakar
  │           └─────────────┘                  │
  │                                             │
  │         ┌─────────────────┐                 │
  │         │    YATAK         │                 │
  │         │  (Kişi uzanır)   │                 │
  │         └─────────────────┘                 │
  └─────────────────────────────────────────────┘
```

### Konum Kuralları

| Kural | Açıklama |
|---|---|
| **Yatak başucu** | Cihaz yatak başucunda, doğrudan yukarı bakacak şekilde |
| **Göz hizasının üstü** | Cihaz yatak seviyesinden yüksekte → ışık gözü almaz |
| **Gizli yerleşim** | Cihaz komodin üstünde ama kitap/bitki arkasına gizli |
| **Tavana doğrudan** | Cihaz 90° yukarı bakar → nebula tavana homojen yansır |
| **Duvara yakın değil** | Cihaz duvardan en az 30cm uzakta → ışık duvara değil tavana yansır |

> **Neden başucu?** Yatakta uzanırken bakılan tek yüzey tavandır. Projeksiyon başucundan yukarı yansırsa, kişi uzandığında tam görüş alanında nebula görünür → "sonsuz derinlik" hissi.

## 🚫 Yeşil Lazer (Yıldız) Neden Kapatılmalı?

### Sorun: "Çocuk Odası" Hissi

Galaksi projeksiyon cihazlarının çoğu iki moddan oluşur:
1. **Nebula (Bulutsu):** Yavaş dönen renkli bulut formasyonu
2. **Yeşil Lazer (Yıldız):** Tavanda noktasal yeşil ışık noktaları

```
  ❌ NEBULA + LAZER (Çocuk Odası)           ✅ SADECE NEBULA (Sinematik Lüks)
  ┌──────────────────────────────┐          ┌──────────────────────────────┐
  │  ·  ·  ·  ·  ·  ·  ·  ·  ·  │          │  ░░░░░░░░░░░░░░░░░░░░░░░░░  │
  │  ·  ·  ·  ·  ·  ·  ·  ·  ·  │          │  ░░░░░░░░░░░░░░░░░░░░░░░░░  │
  │  Yeşil noktalar (lazer)       │          │  Yavaş dönen bulutsu          │
  │  + bulutsu                    │          │  (sadece nebula)              │
  │  "Çocuk odası / oyuncak"      │          │  "Sinematik / lüks otel"       │
  │  Dikkat dağıtıcı              │          │  Sakinleştirici               │
  └──────────────────────────────┘          └──────────────────────────────┘
```

### Estetik Karşılaştırma

| Faktör | Nebula + Lazer | Sadece Nebula |
|---|---|---|
| **Hissi** | "Çocuk odası", "oyuncak" | "Sinematik", "lüks otel" |
| **Dikkat** | Yeşil noktalar gözü yorar | Bulutsu gözü yormaz |
| **Rahatlama** | Lazer noktaları "alarm" hissi | Yavaş bulutsu "hipnotik" hissi |
| **Uyku** | Lazer uyku öncesi gözü uyarır | Bulutsu melatonin salınımını destekler |
| **Premium** | "Disco topu" benzeri | "Interstellar / Inception" benzeri |

> **Altın Kural:** Yeşil lazer KAPALI. Sadece yavaş dönen nebula. Bu, "çocuk odası" hissinden kaçıp "sinematik lüks" hissini korumanın tek yoludur.

## 🎨 Görsel Psikoloji: Yavaş Hareket ve Hipnotik Etki

### Neden Çok Yavaş?

İnsan gözü, yavaş hareket eden görselleri "doğal" algılar. Hızlı hareket = "tehlike/uyarı" sinyali; yavaş hareket = "güvenlik/rahatlama" sinyali.

```
  HIZLI DÖNEN NEBULA                    YAVAŞ DÖNEN NEBULA
  ┌──────────────────────────┐          ┌──────────────────────────┐
  │  ⟳ Hızlı dönme           │          │  ⟲ Çok yavaş dönme        │
  │  Göz takip edemez         │          │  Göz rahatça izler        │
  │  "Disko" hissi            │          │  "Hipnotik" hissi         │
  │  Baş dönmesi               │          │  Derin rahatlama          │
  │  Dikkat dağıtıcı          │          │  Meditatif                │
  └──────────────────────────┘          └──────────────────────────┘
```

### Motor Hızı Ayarı

| Hız | Etki | Kullanım |
|---|---|---|
| **%100 (hızlı)** | Disko/çocuk odası | ❌ ASLA |
| **%50 (orta)** | Hala hızlı, dikkat dağıtıcı | ❌ ASLA |
| **%25 (yavaş)** | Orta-yavaş, kabul edilebilir | ⚠️ Sadece parti modu |
| **%10 (çok yavaş)** | Hipnotik, meditatif | ✅ Varsayılan |
| **%5 (ultra yavaş)** | Neredeyse duruyor, derin rahatlama | ✅ Uyku modu |

> **Öneri:** Motor hızı %10 (çok yavaş). Bu, nebula'nın "döndüğünü" fark ettirmeyecek kadar yavaş ama "canlı" olduğunu hissettirecek kadar hızlıdır. Hipnotik etki için ideal.

### Renk Paleti Psikolojisi

| Renk | Hex | Etki | Kullanım |
|---|---|---|---|
| **Derin Mavi** | #0A0A40 | Derinlik, sonsuzluk, güven | Varsayılan / uyku |
| **Mor** | #2A0A40 | Gizem, yaratıcılık, romantik | Date/lounge |
| **Koyu Pembe** | #400A2A | Tutku, sıcaklık, intim | Intimacy modu |
| **Koyu Lacivert** | #0A0A20 | Sinema salonu, odaklanma | Film modu |
| **Kehribar** | #402A0A | Sıcak, güven, "ev" | Barista/sabah |

> **Kural:** Renkler ASLA parlak değil — her zaman "koyu" tonlar. Parlak renkler gözü yorar; koyu tonlar derinlik hissi yaratır. "Interstellar" filmi gibi — koyu, derin, gizemli.
